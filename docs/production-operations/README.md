# Production operations

Use this folder to back up configuration and operate Record Health Check after it is available to
production users. For investigations, start in the separate diagnostics section.

| Task | Guide |
| --- | --- |
| Investigate a missing, wrong, or unclear result | [Troubleshoot Record Health Check](../diagnostics/browser-console.md) |
| Protect or move Check configuration | [Back up and restore configuration](./back-up-configuration.md) |
| Prepare for and operate after go-live | [Operate in production](./operate-in-production.md) |

For upgrades and removal, use [Start here](../start-here/README.md). For exact limits and Reason
Codes, use the [reference section](../reference/README.md).
