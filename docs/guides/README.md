# Guides

> [!NOTE]
> On this page, choose the guide that helps you decide whether Record Health Check fits, configure
> Check Sets and Checks, troubleshoot results, or operate it in production.

Start with these guides after installing Record Health Check and creating your first Check. If you
have not done that yet, read [How it works](../installation/how-it-works.md) and
[Create your first Check](../installation/create-your-first-check.md).

Follow the recommended path for a complete setup, or choose the task you need now.

## Recommended path

| Step | Guide | What you finish |
| ---: | --- | --- |
| 1 | [Configure Check Sets and Checks](configure-check-sets-and-checks.md) | Build and test a complete review for one Salesforce record type |
| 2 | [Configure action links](configure-action-links.md) | Pair Fix Message with a safe Action Label and URL |
| 3 | [Troubleshoot Record Health Check](troubleshoot-with-show-diagnostics.md) | Prove the configuration with authorized evidence |
| 4 | [Operate in production](operate-in-production.md) | Keep events, diagnostics, backups, and subscribers healthy after go-live |
