# Guides

> [!NOTE]
> After you have installed Record Health Check, use these guides to decide whether it fits, configure Check Sets and Rules, and keep a production org healthy.

Use these **after** install and a first Rule (see
[How it works](../installation/01-how-it-works.md) and
[Create your first Rule](../installation/03-create-your-first-rule.md)).
Work through the path below, or jump via the task table.

## Recommended path

| Step | Guide | What you finish |
| ---: | --- | --- |
| 1 | [Compare to native Salesforce](01-compare-to-native-salesforce.md) | Decide Framework vs Validation Rules, Duplicate Rules, or Flow |
| 2 | [FAQ](02-faq.md) | Short answers on saves, editions, install paths, and Demo Check Sets |
| 3 | [Configure Check Sets and Rules](03-configure-check-sets-and-rules.md) | Design a full readiness review and release checklist |
| 4 | [Configure action links](04-configure-action-links.md) | Pair Fix Message with a safe Action Label and URL |
| 5 | [Understand adaptive card styling](05-choose-card-design-system.md) | One card placement across Lightning and Cosmos styling |
| 6 | [Draft configuration with AI](06-draft-configuration-with-ai.md) | Give an assistant Framework terms and a reviewable output format |
| 7 | [Troubleshoot with Show Diagnostics](07-troubleshoot-with-show-diagnostics.md) | Reveal authorized card and console evidence, then turn it off |
| 8 | [Operate in production](08-operate-in-production.md) | Keep events, diagnostics, backups, and subscribers healthy after go-live |
