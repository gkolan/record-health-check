# Lightning record-page configuration

Use this folder when users need to see and run Record Health Check on a Lightning record page.

1. [Add the Record Health Check card](./configure-the-component.md).
2. Save and activate the page for the app, record type, and profiles that should use it.
3. Open a record as a user with **Record Health Check Card User** access.
4. Confirm the intended Check Set appears and runs.

Use [Theme and accessibility](./theme-and-accessibility.md) to verify keyboard behavior,
responsiveness, and compatibility with the active Salesforce theme.

If the Check Set itself is not ready, return to [Build Checks](../build-checks/README.md). If the
card is present but behaves unexpectedly, use [Troubleshoot](../diagnostics/browser-console.md).
