# Build Checks

> [!NOTE]
> On this page, choose the guide that helps you decide whether Record Health Check fits, configure
> Check Sets and Checks, troubleshoot results, or operate it in production.

Start with these guides after installing Record Health Check and creating your first Check. If you
have not done that yet, read [How it works](../start-here/what-it-does.md) and
[Create your first Check](../step-by-step-guide/create-your-first-check.md).

Follow the recommended path for a complete setup, or choose the task you need now.

Before building, use [Compare Record Health Check with native Salesforce](../start-here/when-to-use-record-health-check.md)
to confirm that advisory guidance is the right behavior. Card-theme and AI-drafting pages are
optional; there is no theme picker, and an AI draft never replaces human review.

## Recommended path

| Step | Guide | What you finish |
| ---: | --- | --- |
| 1 | [Configure Check Sets and Checks](./configure-check-sets-and-checks.md) | Build and test a complete review for one Salesforce record type |
| 2 | [Configure action links](./add-fix-link.md) | Pair Fix Message with a safe Action Label and URL |
| 3 | [Read Record Health Check results](../reference/results/statuses-and-labels.md) | Translate card labels into Flow, Apex, and integration statuses |
| 4 | [Troubleshoot Record Health Check](../diagnostics/browser-console.md) | Prove the configuration with authorized evidence |
| 5 | [Operate in production](../production-operations/operate-in-production.md) | Keep events, diagnostics, backups, and subscribers healthy after go-live |
